실행 python app.py → 접속 http://127.0.0.1:5050/hw1

1) Problem Statement Canvas

고객(Who)

  • 대학생·직장인: 출퇴근/통학/외출 전 빠르게 복장을 결정해야 하는 사용자
  • 야외활동(러닝/등산/데이트) 계획이 있는 일반 사용자
  • 미세먼지·날씨에 민감한 사용자(천식/알러지 등 민감군 포함)

컨텍스트(언제 문제가 발생?)

  • 아침 또는 외출 직전 5분 이내: 여러 앱(날씨/대기질/의류추천)을 번갈아 확인
  • 급변하는 날씨/미세먼지 상황(황사·초미세먼지, 돌풍/소나기)에서 판단이 더 어려움
  • 여러 지역 이동(학교→알바→집) 시 지역별 지표를 각각 찾아야 함

근본 문제(5 Whys 요약)

  1. 왜 결정이 느린가? → 정보가 흩어져 있어 한 화면에서 종합 판단이 어렵다.
  2. 왜 흩어져 있나? → 날씨/대기질/체감온도/강수/바람 정보가 서로 다른 서비스에 분산.
  3. 왜 통합이 안 되었나? → 각 서비스의 지표 단위·등급·시간축이 달라 즉시 비교가 어렵다.
  4. 왜 복장 결정이 더 어려운가? → 지표→행동(무엇을 입을지)로 바꾸는 룰/모델이 없다.
  5. 왜 최종적으로 실수하나? → 급변 상황(소나기·돌풍·PM2.5 급등)에 대한 경고/보강 아이템 제시가 없다.

감정적 영향(Feelings)

  • 불안·귀찮음: 앱/웹을 오가며 비교하는 번거로움
  • 후회·피로: 덥거나 춥게 입어서 불편, 우산/마스크 미지참으로 불쾌감
  • 신뢰 저하: 예보/지표가 제각각이라 어떤 걸 믿어야 할지 혼란

정량화 가능한 영향(Impact)

  • 의사결정 시간: 평균 3~5분 → 통합 시 < 30초 목표
  • 준비물 누락률(우산/마스크): 체감상 주 1~2회 → 경고/추천 후 누락률 50%↓ 목표
  • 불쾌/불편 경험: 덥거나 춥게 입은 날 발생 빈도 월 4회 → 월 1회 이하 목표
  • 재확인 횟수: 아침·점심·퇴근 전 2~3회 → 요약 배지/알림으로 1회 이하

대안(현재 고객이 하는 방식)

  • 날씨 앱 + 대기질 앱을 각각 열어 수치·등급을 수동 비교
  • 포털 검색으로 시간대별 예보를 확인하고 경험적으로 복장 결정
  • 우산·겉옷 등은 “혹시 몰라” 챙기거나 아예 포기

대안의 단점(Why not good enough)

  • 시간 소모: 여러 앱 이동/수치 비교에 매번 3~5분
  • 정합성 부족: 지표 단위·등급 차이로 즉시 판단 어려움
  • 행동 연결 부재: “무엇을 입을지/무엇을 챙길지”로 바로 변환되지 않음
  • 급변 대응 약함: 소나기/돌풍/PM 급등 같은 예외 상황에 대한 보강 아이템 제안 없음

2) 만들 솔루션 (3줄)

① 위치/시간으로 날씨(체감온도·강수·풍속)와 미세먼지를 조회해 외출 적합도(0~100)를 계산한다.

② 점수·환경값을 바탕으로 룰 기반 복장/아이템(우산·마스크·겉옷)을 즉시 추천한다.

③ 오늘/내일 시간대별 기온·PM2.5·강수·풍속을 미니 차트로 제공하고, 지역을 즐겨찾기로 저장한다.

3) 기능 명세

  • 위치 입력: 현재 위치(GPS) 사용 또는 검색어로 지역 선택
  • 데이터 수집: OpenWeatherMap(체감온도·강수·풍속·예보), AirKorea(PM2.5/PM10)
  • 외출 적합도 산식: 온도쾌적도(40) + 대기질(35) + 강수(15) + 풍속(10) → 0~100 점수
  • 복장 추천: 체감온도 구간별 기본 복장 + 강수/풍속/미세먼지 조건부 아이템(우산·마스크 등)
  • 시각화: 오늘/내일 시간대별 기온·PM2.5·강수·풍속 미니 차트
  • 캐싱: API 호출 10~15분 서버 캐시로 비용/지연 최소화
  • 오류 처리: API 장애 시 마지막 정상 데이터와 안내 문구 노출
  • 저장(선택): 즐겨찾는 지역 추가/삭제 및 최근 조회 기록

4) 간단한 UX 흐름

  • 홈 화면
  • 위치 선택
    • 현재 위치 사용
    • 검색으로 위치 입력
  • [조회] 버튼 클릭
  • 상단 요약
    • 외출 적합도 점수(색상 배지)
    • 체감온도·강수·풍속·PM2.5 요약
  • 중앙 추천
    • 복장 추천 카드(필수/선택 아이템)
  • 하단 차트
    • 시간대별 기온·PM2.5·강수·풍속
    • 탭 전환으로 지표 변경
  • 즐겨찾기
    • 지역 추가/삭제 및 빠른 재조회
