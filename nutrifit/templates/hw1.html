NutriFit 개인 맞춤 건강식/운동 추천 (Flask 주제/계획서-hw1)

실행 python app.py → 접속 http://127.0.0.1:5050

1) Problem Statement Canvas

고객(Who)

  • 식단·활동을 기록하는 20~40대 직장인 / PT 회원
  • 헬스케어 스타트업, 피트니스 센터, 보험사 웰니스 팀
  • 스마트워치·식단 앱을 운영하는 데이터 분석가

컨텍스트(언제 문제가 발생?)

  • 칼로리 합계만 제공돼 영양 균형과 피로도를 동시에 파악하기 어려움
  • 운동 루틴이 일정·컨디션과 연결되지 않아 지속성이 낮음
  • 데이터가 기기/앱마다 분산돼 통합 인사이트가 없음

근본 문제(5 Whys 요약)

  1. 왜 몸 상태를 실시간 파악 못하나? → 심박/식단/수면 로그가 흩어짐.
  2. 왜 영양 밸런스가 무너지나? → 칼로리 위주 기록으로 미량영양 추적 부재.
  3. 왜 운동을 꾸준히 못하나? → 추천 루틴이 생활 패턴과 연결되지 않음.
  4. 왜 인사이트가 늦나? → API/CSV를 수동으로 합쳐야 함.
  5. 왜 코칭 효과가 낮나? → 행동 알림/피드백 루프가 부족함.

감정적 영향(Feelings)

  • 사용자: 꾸준히 기록하지만 개선 포인트를 몰라 좌절
  • 트레이너: 회원 데이터를 수기로 정리하느라 피로
  • 서비스 운영자: 낮은 참여율과 해지율에 대한 압박

정량화 가능한 영향(Impact)

  • 칼로리 편차 ±400kcal → 감량/근육 목표 달성률 30%↓
  • 운동 이행률 20%p 향상 시 PT 재등록률 1.3배 상승
  • 개인화 추천 클릭률 30% 이상 확보 시 구독 전환율 15%+
  • 수면/활동 데이터를 보험사 웰니스 리워드와 연동 가능

대안(현재 고객이 하는 방식)

  • 칼로리 계산 앱 + 엑셀 수기 관리
  • 스마트워치 기본 리포트만 참고
  • 트레이너가 주간 피드백을 카톡/메일로 전달

대안의 단점(Why not good enough)

  • 영양·수면·운동 데이터를 함께 보지 못해 인사이트가 단편적
  • 지속적 알림/동기부여 기능이 부족해 실행률이 낮음
  • 데이터 품질·보안 기준이 개인 기기에 의존

2) 만들 솔루션 (3줄)

① 스마트워치·식단 로그·공공 영양 DB를 스트리밍으로 수집해 개인 맞춤 건강 데이터 레이크를 구성한다.

② 체성분/목표를 반영한 영양 밸런스 & 운동 루틴 추천 엔진으로 부족/과잉을 실시간 리밸런싱한다.

③ 액션 보드에서 식단/운동 시나리오와 코칭 알림을 제공해 습관 형성을 돕는다.

3) 기능 명세

  • 데이터 커넥터: 스마트워치 API, 식단 CSV, 공공 칼로리 DB 동기화
  • 영양 밸런스 분석: 탄·단·지, 미량 영양소 편차 계산 및 권장량 제안
  • 운동 루틴 추천: 체지방률·선호도 기반 HIIT/근력/요가 조합 생성
  • 코칭 알림: 부족 영양소, 휴식 필요, 스트레스 징후를 모바일/챗봇으로 전달
  • 데이터 파이프라인: Airflow 스케줄링, 품질 지표 모니터링, 익명화 처리
  • 리포트: 주간 PDF/CSV 내보내기 및 트레이너 공유

4) 간단한 UX 흐름

  • 온보딩: 목표(감량/근력/컨디션)와 현재 체성분·식습관 입력
  • 데이터 연결
    • 스마트워치 계정 인증, 식단 CSV 업로드
    • 알레르기/식단 선호, 활동 시간대 설정
  • [동기화] 버튼으로 실시간 파이프라인 시작
  • 대시보드
    • 섭취 칼로리 vs 목표, 탄단지 비율, 활동 칼로리 카드
    • 수면/스트레스 레이더, 체중 추세 차트
  • 추천 루틴
    • 부족 영양소 보충 식단 제안
    • 근력/유산소/휴식 루틴과 난이도 표시
  • 코칭 & 공유
    • 알림 내 완료/미루기 버튼으로 행동 추적
    • 트레이너·친구에게 주간 리포트 공유
